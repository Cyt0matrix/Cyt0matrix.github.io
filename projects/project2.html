Project 2: Detection Engineering & Custom SPL Alerts

Category: Detection Engineering & Threat Analytics

Objective

Transition from passive log collection to active detection engineering by writing precise Splunk Processing Language (SPL) queries, overcoming XML-rendering extraction challenges, and converting queries into threshold-based SOC alerts.

Attack Simulation & Telemetry

Executed discovery commands (whoami /all, ipconfig /all, net user) to simulate post-compromise reconnaissance and generate raw Sysmon Event ID 1 telemetry.

Detection Logic & Regular Expression Parsing

Because logs rendered in XML format (renderXml = true), standard fields required dynamic regular expression extraction to isolate arguments. 

index="windows_logs" (whoami OR ipconfig OR "net user")
| rex field=_raw "<Data Name=\"CommandLine\">(?<cmd>[^<]+)</Data>"
| table _time Hostname Image cmd User

SOC Alert Automation

Converted the query into an automated threshold alert named Suspicious Host Enumeration Activity configured to log structured events back into the SIEM index when results exceed zero.
