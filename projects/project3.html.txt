            <p style="color: var(--accent); font-weight: bold; margin-bottom: 24px;">Category: Incident Response & SOC Operations</p>
            
            <h2>Objective</h2>
            <p>
                Bridge the gap between detection alerts and operational response by authoring a formal Security Operations Center (SOC) Incident Report (INC-2026-001) for host discovery activities.
            </p>

            <h2 style="margin-top: 40px;">Incident Overview</h2>
            <ul style="color: var(--muted); margin-left: 20px; margin-bottom: 20px;">
                <li><strong>Incident ID:</strong> INC-2026-001</li>
                <li><strong>Severity:</strong> Medium</li>
                <li><strong>Detection Source:</strong> Splunk SIEM Alert (<code>Suspicious Host Enumeration Activity</code>)</li>
                <li><strong>Affected Asset:</strong> Windows 10 Endpoint (`192.168.0.3`)</li>
                <li><strong>Detection Vector:</strong> Sysmon Event ID 1 (Process Creation) matching reconnaissance binaries.</li>
            </ul>

            <h2 style="margin-top: 40px;">Analyst Triage Workflow</h2>
            <p>
                <strong>Step 1 - Alert Validation:</strong> Reviewed the triggered alert in Splunk Web, noting multiple discovery commands executing in rapid succession.<br>
                <strong>Step 2 - Raw Telemetry Query:</strong> Executed dynamic regex parsing to isolate command-line parameters and confirm process execution paths.<br>
                <strong>Step 3 - Scope & Context Analysis:</strong> Inspected parent process artifacts and user context to distinguish authorized administrative tasks from malicious internal reconnaissance.
            </p>

            <h2 style="margin-top: 40px;">Conclusion & Remediation</h2>
            <p>
                Classified the event as a <strong>Controlled Simulation (True Positive - Authorized Testing)</strong>. Verified that detection engineering controls successfully identified post-compromise enumeration behavior without generating false positive fatigue.
            </p>
